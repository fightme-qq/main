# Xollonox Horror — аудит и статус этапов

Документ фиксирует результаты Этапа 1 (аудит) и то, что сделано в следующих
этапах. Обновляется по мере продвижения; разделы «Осталось» — это не заглушки, а
честный список нереализованного.

## 1. Исходное состояние проекта

Зафиксировано до изменений (коммит `ed1af99`):

- Voxel sandbox на Three.js `0.185`, Vite 7, ESM, без внешних рантайм-зависимостей
  кроме `three`.
- `src/` — 58 527 строк JS в 167 модулях: `world` (50), `rendering` (24),
  `entities` (17), `ui` (19), `player` (12), `progression` (10).
- Мир: чанки 16×16, мешер в Web Worker, `WorldWorkerPool`, кастомный voxel-шейдер
  (`Materials`), запечённое освещение неба/блоков, точечные источники света от
  эмиссивных блоков (`ShaderManager.MAX_POINT_LIGHTS`).
- Сохранения: формат v9 (`SAVE.worldFormatVersion`), миграции с v7/v8.
- Мобы: инстансированный рендер, скелеты и клипы в данных (`MobSkeletons`),
  ИИ-цели в `ai/MobGoals.js`, `ai/MobBrain.js`, навигация `ai/VoxelNavigator.js`,
  спавн `MobSpawner.js` с учётом света и дня/ночи.
- Звук: полностью процедурный синтез в `audio/SoundRegistry.js` (без файлов,
  без сети).
- Настройки: `SettingsSchema` + пресеты `potato/low/medium/high/ultra`.

### Базовая проверка (до изменений)

```
npm run check   # audit + 8 selftest-наборов + production build
```

Результат: `audit` — 167 модулей, 557 импортов, ошибок нет; все self-test
наборы зелёные; `vite build` — 190 модулей, `dist/` собирается за ~2.4 с.
Исходная версия стабильна, регрессий до начала работ не зафиксировано.

## 2. Найденные дефекты и разрывы с ТЗ

### P0-1. Внешний вид существ (подтверждено в коде)

`MobRenderer` использовал **один** атлас-тайл на всё существо:
`buildMobGeometry` брал UV из `BoxGeometry`, а шейдер растягивал единственный
тайл (`uTileRect`) на каждый бокс. Следствия:

- нет лица, глаз, морды, клюва, копыт — только пятна;
- корова, зомби и крипер отличаются лишь оттенком шумовой текстуры;
- направление взгляда существа не читается, силуэт в тумане обезличен;
- UV брались в ориентации `BoxGeometry` без учёта `flipY = false` атласа, то
  есть даже рисунок тайла ложился на боксы перевёрнутым.

### P0-2. Туман не зависит от времени и биома

`LightingSystem._updateFog` считал `near/far` только из render distance,
`graphics.fogDensity` и погоды. Ночь меняла **цвет**, но не **дальность
видимости**: игрок видел так же далеко, как днём, и легко «отменял» ночь
яркостью монитора. Не было ни профилей биомов, ни низин, ни пещер, ни API для
временного усиления тумана событиями.

### P0-3. Ночь не давала силуэтов

Цвет ночного тумана (`0.05, 0.06, 0.11`) был темнее или равен освещённой
геометрии, поэтому деревья и постройки не отделялись от фона: сцена
превращалась в однотонную тёмную картинку вместо читаемых силуэтов.

### P1-4. Нет механики шума

`MobEntity`/`MobBrain` не знают о шуме: нет ни источников, ни затухания, ни
реакции ИИ. `MobBrainState` содержит только `IDLE/WANDER/CHASE` — нет
`INVESTIGATE/DETECT/SEARCH/RETREAT`.

### P0-5. Аудиобиблиотеки ElevenLabs нет

Звук синтезируется в рантайме. Нет ни манифеста, ни пакетного генератора, ни
загрузки файлов, ни категорий `Creatures/Horror/Player` в настройках
(сейчас `master/music/ambient/blocks/weather/ui`).

## 3. Что реализовано

### 3.1. Скины существ (P0-1 закрыт)

Новые файлы:

- `src/config/MobSkins.js` — таблица стилей на 46 существ: палитра
  (`base/accent/eye`), рисунок (`fur/wool/spots/stripes/feathers/scales/bone/
  rot/slime/cloth/armour/glow/void`), тип лица (`mammal/bird/humanoid/skull/
  insect/slime/void/mask`), флаг свечения глаз. Плюс отображение «кость → роль
  скина» и «бокс → роль скина».
- `src/world/MobSkinTiles.js` — имена тайлов `mob_<id>_<head|body|limb|accent>`,
  добавляются в конец `TILE_NAMES` (индексы атласа — контракт совместимости).
- `src/rendering/TextureAtlas.js` — процедурная отрисовка четырёх тайлов на
  существо: лицо с глазами/мордой/клювом/глазницами, рисунок тела, затемнённая
  конечность с полосой копыта, акцентный тайл.
- `src/entities/MobRenderer.js` — UV запекаются в геометрию по боксам: каждая
  грань получает координату из нужного тайла, передняя грань головы — под-регион
  лица (`MOB_FACE_RECT`), остальные грани головы —plain-полоса. Шейдер больше не
  использует `uTileRect`.

Итог: 46 существ × 4 роли = 184 тайла; атлас занят на 631 из 1024 ячеек.

### 3.2. Туман по биомам и времени (P0-2, P0-3 закрыты)

- `src/config/AtmosphereConfig.js` — чистые функции и данные:
  `FOG_BIOME_PROFILES` (лес/тёмный лес/тайга/джунгли/болото/равнина/пустыня/
  горы/океан и т.д.), `fogVisibilityFactor({biome, daylight, y, extraDensity})`,
  `caveFogAmount(y)`, `fogBiomeTint(biome)`, интервалы опроса биома по тиру
  качества.
- Глобальный ночной коэффициент `NIGHT_VISIBILITY = 0.55` умножен на биомный
  профиль: ночь забирает около половины линии видимости в любом биоме, а биом
  добавляет своё (лес ×0.8, болото ×0.56). Иначе «ясная равнина ночью» была бы
  такой же открытой, как днём.
- `src/rendering/LightingSystem.js` — опрос биома по таймеру (0.2–0.5 с в
  зависимости от пресета) и только при смещении > 4 блоков; сглаживание
  видимости и тона (экспоненциальное, ~0.55 с) — на границе биомов нет скачка;
  низины плотнее, гребни чище; пещеры дополнительно закрывают и затемняют туман;
  при render distance 8 ночью дальность падает примерно до 62 блоков на равнине,
  ~50 в лесу и ~38 в болоте (днём — 120).
- Ближняя граница тумана сжимается сильнее дальней, поэтому ночь читается как
  «закрытое пространство», а не как серая стена вдалеке.
- Ночные кейфреймы неба переработаны: холоднее ambient, туман чуть светлее
  геометрии (силуэты), луна 0.26.
- `setFogBoost(0..1)` — API для будущих событий/грозы.
- `getAtmosphereStats()` — для отладочного оверлея и тестов.

### 3.3. Темп, музыка и режиссёр напряжения (по замечанию «нет нагнетания»)

- **Сутки перестроены.** Цикл — 20 реальных минут (`TIME.secondsPerDay = 1200`):
  день ~5.5 мин, сумерки/рассвет ~5 мин, ночь ~9 мин. Фазы заданы окнами в
  `src/config/DayCycle.js` (`phaseAt`), а не порогами яркости: плоская вершина
  `smoothstep` растягивала день на треть цикла. Ночь — самая длинная фаза
  (46%), день — короткая (28%).
- **Мир открывается в сумерках**, а не в ясный полдень: `TIME.startTime = 0.62`
  (до ночи ~1.5 минуты). Для старых сохранений с дневным временем есть настройка
  `gameplay.startAtDusk` (по умолчанию включена): при загрузке день
  переписывается на сумерки. Отключается одним тумблером.
- **День больше не «ясный».** Солнце ослаблено (2.0 вместо 2.6), небо
  перекрашено в пасмурные холодные тона, ambient ниже, туман на горизонте
  постоянный (`DAY_VISIBILITY = 0.78`), насыщенность принудительно ×0.82, облака
  плотнее (coverage 0.6–0.66 во всех пресетах), виньетка сжимается с наступлением
  темноты (`darkness` в постобработке). Днём тоже играют редкие далёкие события
  (раз в 75–150 с), а под всей сценой держится низкий гул (0.07 днём → 0.18
  ночью).
- **Кейфреймы неба** переразмечены под новый цикл: рассвет 0.22, полдень 0.46,
  золотой час 0.56, поздние сумерки 0.64, ночь с 0.70. Солнце всходит в 0.22 и
  садится в 0.70, поэтому «сумерки» на цветовом рампе совпадают с реальным
  закатом.
- **Музыка.** Шесть инструментальных треков через `/v1/music`: день, сумерки,
  две ночи, пещера, меню. Играют стриминговыми лупами; `setMusicPhase` держит
  ровно один слой и кроссфейдит остальные.
- **Режиссёр напряжения** (`src/gameplay/TensionDirector.js`): далёкие события
  каждые 22–52 с ночью, 38–78 с в сумерках, 40–85 с в пещере; событие не
  повторяется дважды подряд и ставится в кольцо 10–26 блоков вокруг игрока
  (слышно направление); сердцебиение поднимается от низкого здоровья и глубины
  ночи; в меню/на паузе события молчат.
- **Шаги переделаны.** 6 поверхностей × 5 вариантов, файлы по 0.8 с с промптом
  «ровно один шаг, без второго»; спринт громче и чуть выше по тону. Прыжок,
  приземление, плавание, еда, бой, щит, лук и поломка инструмента получили
  собственные записи (142 файла всего).

### 3.4. Мобы и ИИ (по замечанию «сделай мобов»)

Три роли добавлены как полноценные существа, а не перекрашенные зомби: свои
модели, скины, анимации, мозг, звуки и вес в спавне.

- **Странник** (`walker`) — высокий медленный двуногий, 34 HP. Замечает игрока,
  замирает на 0.9 с (рычит), затем идёт без остановки. Потеряв цель, идёт к
  последнему месту, где её видел, ищет 10 с, затем возвращается домой.
- **Охотник** (`hunter`) — низкий четвероногий, 26 HP, скорость 4.1 (быстрее
  спринта). Реакция 0.25 с, слышит шум в радиусе 22 блока, ищет недолго и
  агрессивно. Его звуки слышно до появления.
- **Скрывающийся** (`stalker`) — очень высокий тонкий силуэт, 18 HP. Держится в
  кольце 12–17 блоков, наблюдает и шепчет. Не атакует; если смотреть на него
  дольше 1.4 с или подойти ближе 8 блоков — уходит быстрым шагом и исчезает,
  только когда игрок его не видит (без телепортаций и без события смерти).

Механика:

- `src/entities/ai/HorrorBrain.js` — состояния `idle/roam/investigate/detect/
  chase/attack/search/retreat/observe`, простые и проверяемые: без мира и
  Three.js, на входе дистанция, видимость, взгляд игрока и шум.
- `src/gameplay/NoiseSystem.js` — затухающие импульсы шума: шаг 9 блоков, спринт
  18, добыча блока 22; охотник реагирует на них, странник почти глух, stalker
  игнорирует шум.
- Навигация: мозг просит точку (`navigateTo`), а не направление, поэтому поиск и
  проверка шума обходят стены через существующий `VoxelNavigator`.
- Спавн: веса (`spawnWeight`: странник 1.5, охотник 1.1, скрывающийся 0.85),
  обычные ночные/темновые правила, дистанция 24–56 блоков от игрока.
- Звуки: `src/entities/MobSounds.js` привязывает реакции к записям
  (`creature_walker_*`, `creature_hunter_*`, `creature_stalker_*`); урон, атака и
  смерть звучат позиционно, состояние — рычание при обнаружении, шаги в
  преследовании, шёпот и исчезновение у скрывающегося.

### 3.5. Главный экран (по замечанию «оставь одну кнопку плей»)

- На главном экране теперь **одно основное действие — Play**. Оно продолжает
  самый свежий сохранённый мир, а если сохранений нет (или все они — проигранные
  one-life миры) сразу создаёт новый: **survival, normal, пресет medium**, без
  диалогов и ввода сида.
- Дополнительные действия вынесены в две тихие кнопки: **World options**
  (имя, сид, пресет, сложность, импорт сохранения) и **Settings** (обычные
  настройки). Отдельной кнопки «New world» и «Import save» на главном экране
  больше нет; импорт живёт в World options.
- В списке миров убрана кнопка Play у каждого мира: строка мира сама кликабельна
  (Enter/пробел тоже работают), остались только Export и Delete. Проигранный
  one-life мир по-прежнему не открывается и помечен «World lost».
- Первый запуск использует пресет **medium** вместо рекомендованного устройством
  (устройство всё равно ограничивает настройки через `constrainPresetToDevice`),
  а режим по умолчанию — survival.
- Проверка: `npm run menu:browser` — реальный браузер, меню из трёх кнопок,
  отсутствие лишних, клик Play → мир `survival/normal/medium` без диалога,
  отсутствие ошибок консоли.

## 4. Проверено

- `npm run check` — зелёный: `audit-imports`, все 8 прежних self-test наборов,
  `selftest:horror` (**114/114**), production build.
- `npm run visual:horror` — headless Chromium + SwiftShader, мир с фиксированным
  сидом, **19 существ** в кадре. Скриншоты: `dist-smoketest/visual/`
  (`world-start.png`, `mob-lineup-day.png`, `mob-lineup-night.png`,
  `night-fog.png`, `dusk-fog.png`). Проверки изображения автоматические:
  - все 19 существ попали в кадр;
  - у каждого в окне головы ≥ 6 различных цветов (текстура, а не заливка);
  - в тайле головы каждого существа присутствуют пиксели цвета глаз (или тёмные
    глазницы черепа) — лица реально нарисованы, включая три роли;
  - ночной кадр темнее дневного (средняя яркость 71 против 159) и не чёрный;
  - ночной туман закрыт: при render distance 4 — `near 17.5 / far 29.2`,
    видимость 0.486 от расчётной;
  - voxel-шейдер не ушёл в fallback, ошибок в консоли нет.
- `npm run mobs:browser` — живой мир в режиме survival, ночь: все три роли
  появляются; странник переходит из обнаружения в преследование; охотник
  сокращает дистанцию; скрывающийся наблюдает, уходит от взгляда, исчезает без
  события смерти; импульс шума заставляет охотника проверить точку; голоса
  существ реально воспроизводятся.
- `npm run menu:browser` — реальный браузер: на главном экране ровно три видимые
  кнопки (`Play`, `World options`, `Settings`), нет `New world` и `Import save`;
  один клик Play создаёт мир `survival / normal / medium` без диалога; на первом
  запуске пресет тоже medium; ошибок в консоли нет.
- Прямой замер `fogVisibilityFactor` (node): ночь на равнине/лугу ~0.46–0.49,
  день с дымкой ~0.8; лес ночью ниже, болото ниже леса.
- `npm run audio:qc` — 142 файла декодированы в Chromium: 142 чистых,
  0 предупреждений (длительность, пик, RMS, клиппинг, ведущая/хвостовая тишина,
  число ударов в шаге, нормализационная громкость).
- `npm run audio:browser` — в живом мире: AudioContext `running`, манифест на
  142 записи, декодированные one-shot'ы, 58 ключей с вариантами, стриминговые
  лупы стартуют из кадрового цикла, играют шаги/прыжок/приземление/плавание и
  боевые ключи, слайдер `Creatures` управляет своим gain-узлом, позиционный звук
  идёт через `PannerNode`, ночь переключает музыку, ошибок консоли нет.
- Ключ ElevenLabs отсутствует в исходниках, конфигурации и отчётах (проверено
  поиском по репозиторию); он использовался только как переменная окружения.

Ограничение: визуальная оценка «нравится/не нравится» по скриншотам и
прослушивание звуков требуют человеческого восприятия — автоматика подтверждает
наличие лиц, текстур, тумана, формата и громкости, но не художественное качество.
